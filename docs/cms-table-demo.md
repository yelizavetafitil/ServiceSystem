# Пробная статья: таблица с объединёнными ячейками

## Как создать такую таблицу в CMS

1. **Контент** → **Туториалы** → создайте материал или откройте «Демо: таблица ограничений Zulu».
2. В редакторе переключитесь в режим **Markdown** (иконка `</>` или исходный текст).
3. Вставьте блок **HTML** ниже (Python-Markdown сохраняет теги `<table>`; для `rowspan` нужен именно HTML, не «| col | col |»).
4. Нажмите **Preview** (глаз) — вид должен совпадать с опубликованной статьёй.
5. Отметьте **Опубликовано** и сохраните.
6. Для заказчика: в карточке договора включите доступ к этому туториалу (если нужно).

Простые таблицы без объединения ячеек можно набрать кнопкой **Table** на панели редактора.

---
