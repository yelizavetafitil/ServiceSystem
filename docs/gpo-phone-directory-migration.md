# Миграция ГПО-справочника (Минэнерго) в портал

Цель: заменить разрозненные файлы (каталог `Телефоны МинЭнерго`, устаревшие Excel/Word) единым **интерактивным справочником** в сервисе ЭМСТПН: поиск, фильтр по организации/подразделению, **QR + vCard** для смартфона.

## Что предложить руководству

1. **Единый источник правды** — контакты ведутся в CMS портала (ответственный: служба сопровождения / админ).
2. **Структура по ТЗ**: организация → подразделение → ФИО, должность, внутренний/мобильный, email.
3. **Доступ**: сотрудники заказчиков видят контакты своей РУП + блок УНП «Белнипи»; сотрудники института — полный справочник (по политике доступа).
4. **Обновления** без «пересылки файла на диск S:» — публикация в CMS, пользователи всегда видят актуальную версию.

## Как «оживить» допотопный справочник с помощью ИИ

1. Собрать исходники: Excel, Word, PDF, HTML с `S:\Телефоны МинЭнерго` (или аналог).

### PDF «Телефонный справочник Белэнерго 2024»

Типичный файл — **~570 страниц без текстового слоя** (скан/картинки). В репозиторий **не кладём** (объём, персональные данные). Для импорта в портал:

1. **Пилот:** 5–10 страниц одного управления → OCR (ABBYY, Adobe, Google Drive «скан в текст») или фото → ИИ → CSV по шаблону `scripts/directory-import-template.csv`.
2. Сверка ФИО/телефонов с оригиналом.
3. Импорт в CMS (**Справочник → CSV**) или `python scripts/import_phone_directory.py файл.csv --dry-run`.
4. После успеха пилота — батчами по разделам PDF (не всё сразу).

Автоматический OCR в проекте пока **не подключён** (нужен Tesseract/облачный OCR на стороне заказчика).
2. Экспорт/копирование в **текст или таблицу** (из Word/PDF — через распознавание или ручной фрагмент + ИИ).
3. Дать нейросети **шаблон CSV** (файл `scripts/directory-import-template.csv`) и промпт:

   > Преобразуй приложенный телефонный справочник в CSV UTF-8 с разделителем `;`.  
   > Колонки: `organization;department;full_name;position;phone_internal;phone_mobile;email`.  
   > Одна строка — один человек. Пустые поля оставь пустыми.  
   > Организацию пиши полностью (РУП «…энерго»). Подразделение — из шапки раздела файла.  
   > Телефоны нормализуй: внутренний — как в справочнике, мобильный — +375 …  
   > Не выдумывай контакты; если данных нет — пропусти строку.

4. Проверить выборочно 10–20 записей (ФИО, должность, внутренний).
5. Загрузить в портал: **Админ → Справочник → Импорт CSV** (или CLI `python scripts/import_phone_directory.py файл.csv`).

## Импорт в систему

| Способ | Когда использовать |
|--------|-------------------|
| CMS → CSV | Массовая загрузка после подготовки таблицы ИИ/Excel |
| CMS → .vcf | Контакты из Outlook / CRM |
| CMS вручную | Единичные правки, новые сотрудники |

## Рекомендуемая иерархия для ГПО

- **organization** — РУП / УНП / подведомственная организация.
- **department** — управление, цех, служба (как в штатном расписании или телефонной книге).
- Периодическая **ревизия** (раз в квартал): сверка с кадровой/АТС, снятие уволенных через «Отключить контакт» (аудит).

## Пилот

1. Один филиал (например Брестэнерго) + блок Белнипи — 50–100 записей.
2. Обратная связь от 5–10 пользователей (поиск, QR на телефон).
3. Масштабирование на остальные РУП после утверждения регламента ведения.
