Внешние календари

Задачи с датами попадают в календарь ARM и могут синхронизироваться с Google, Яндекс или Apple.

Как настроить

  1. Только чтение в Google / Outlook / телефоне — скопируйте ссылку экспорта ниже и добавьте «Подписку на календарь» / «Calendar by URL» в приложении календаря. Обновление — по расписанию клиента (обычно раз в несколько часов).
  2. Двусторонняя синхронизация — укажите секретный URL ICS или адрес CalDAV-коллекции, логин и пароль, включите «Двусторонняя синхронизация», нажмите «Сохранить», затем «Синхронизировать сейчас». Импорт подтягивает даты задач из календаря; экспорт отправляет события ARM наружу.
  3. Google — в настройках календаря: «Интеграция календаря» → секретный адрес в формате ICS. Для записи нужен CalDAV (логин Google, пароль приложения) и URL коллекции; поддержка PUT зависит от типа аккаунта.
  4. Яндекс — «Экспорт» → ссылка ICS для импорта; для CalDAV — логин Яндекса и пароль приложения, URL вида https://caldav.yandex.ru/calendars/….
  5. Apple (iCloud) — пароль приложения Apple ID; CalDAV: https://caldav.icloud.com/… (путь к календарю из настроек macOS/iOS).

События задач имеют UID вида project-task-<id>-<user>@servicesystem — по ним при импорте обновляются даты в карточках задач.
